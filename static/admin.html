Администрирование

Управление справочниками отдельно от клиентского калькулятора

Здесь остаются CRUD-операции по `place`, `power`, `kbm`, `age_experience`, `season`, `limitation` и `base_price`. API защищён Bearer-токеном.

Маршруты: `/admin/*` Авторизация: `Bearer ADMIN_TOKEN`

Форма редактирования

Выберите модель и загрузите шаблон payload.

Статус операций появится здесь.

Текущие записи

Клик по записи подставляет `ID` и payload в форму выше.

Нажмите «Обновить список», чтобы загрузить данные.
