# Загрузка справочников

В проекте есть два отдельных сценария загрузки данных в MongoDB.

## Базовые коэффициенты

Загружает коэффициенты ОСАГО, диапазоны мощности, классы КБМ, возраст/стаж, сезонность, ограничения и базовый тариф.

```bash
cargo run --bin seed_reference_data
```

Источник данных:

- `data/osago_reference_data.json`

Поведение:

- подключается к `MONGODB_URI`, если переменная задана;
- иначе использует `mongodb://localhost:27017`;
- очищает коллекции `limitations`, `powers`, `seasons`, `kbms`, `age_experiences` и `base_prices`;
- создаёт новую запись `BasePrice` с текущим `created_at`.

## Территориальные коэффициенты

Загружает `Place` из HTML-снимка.

```bash
cargo run --bin seed_places
```

Источник данных:

- `data/place.html`

Поведение:

- подключается к `MONGODB_URI`, если переменная задана;
- иначе использует `mongodb://localhost:27017`;
- делает upsert по полю `name`;

## Порядок инициализации

1. Поднять MongoDB.
2. Запустить `seed_reference_data`.
3. Запустить `seed_places`.
4. Запустить основной сервер.

## Что важно помнить

- Для территории и мощности используется поле `coefficient`.
- Последняя запись `BasePrice` определяется по `created_at`.
- Повторный запуск `seed_reference_data` полностью пересоздаёт большинство справочников.
- Повторный запуск `seed_places` обновляет или добавляет записи по названию региона.
