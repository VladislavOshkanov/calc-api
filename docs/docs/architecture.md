# Архитектура

Сервис построен на `Axum` и состоит из трёх основных слоёв:

1. **HTTP-роутер** — собирает публичные, административные и статические маршруты.
2. **Контроллеры** — реализуют CRUD-операции и расчёт коэффициента.
3. **MongoDB** — хранит справочники и базовые цены.

## Поток запроса

### Публичный интерфейс

- Главная страница `GET /` отдаёт `static/index.html`.
- Статические ресурсы доступны через `GET /static/*`.
- `GET /api/all-models` возвращает все справочники одним ответом.
- `POST /api/calculate-coefficient` загружает выбранные записи из MongoDB, применяет правила расчёта и возвращает коэффициент вместе с диапазоном цены.

### Админский интерфейс

- `GET /admin` и `GET /admin/` отдают `static/admin.html`.
- Все API-маршруты `/admin/*`, включая `GET`, защищены middleware `admin_auth`.
- Токен берётся из переменной окружения `ADMIN_TOKEN`.
- Если переменная не задана, код использует значение `test_admin_token`.

## Структура модулей

- `src/controller/*` — HTTP-обработчики.
- `src/model/*` — структуры MongoDB и DTO для создания записей.
- `src/auth/*` — middleware авторизации.
- `src/main.rs` — точка запуска сервера.

## База данных

- Основной сервер подключается к MongoDB по адресу `mongodb://localhost:27017`.
- Сидеры поддерживают переопределение адреса через `MONGODB_URI`.
- Все данные хранятся в базе `openapi`.

## Правила расчёта

Итоговая цена считается как произведение:

`Базовый тариф × КТ × КБМ × КО × КВС × КМ × КС`

Где:

- `КТ` — коэффициент территории (`places`)
- `КБМ` — коэффициент бонус-малус (`kbms`)
- `КО` — коэффициент ограничения (`limitations`)
- `КВС` — коэффициент возраста и стажа (`age_experiences`)
- `КМ` — коэффициент мощности (`powers`)
- `КС` — коэффициент сезонности (`seasons`)
- `Базовый тариф` — последняя запись из `base_prices` по `created_at`

Дополнительные правила:

- если `limitation.limited = false`, сервис использует `КБМ = 1.0` и `КВС = 1.0`;
- если `season.months >= 9`, сервис использует `КС = 1.0`.
