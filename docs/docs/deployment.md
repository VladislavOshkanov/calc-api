# Развёртывание

## Переменные окружения

- `ADMIN_TOKEN` — токен для доступа к административным маршрутам.
- `MONGODB_URI` — используется сидерами.

## Рекомендуемая схема

1. Подготовить MongoDB.
2. Загрузить справочники.
3. Запустить основной Rust-сервис.
4. Отдельно опубликовать Docusaurus-документацию как статический сайт.

Сейчас основной сервер не читает `MONGODB_URI` и подключается к `mongodb://localhost:27017`, поэтому это нужно учитывать при production-развёртывании.

## Сборка документации

```bash
cd docs
npm install
npm run build
```

Готовый сайт будет в директории `docs/build`.

## Сборка сервиса

```bash
cargo build --release
```

## Замечания по безопасности

- Для production обязательно задайте `ADMIN_TOKEN`.
- Не публикуйте административные API без ограничения доступа.
- Следите, чтобы MongoDB была доступна только доверенным клиентам.
