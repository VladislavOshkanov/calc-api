# Введение

Сервис предоставляет REST API и веб-интерфейс для расчёта стоимости ОСАГО. MongoDB хранит справочники коэффициентов и базовый тариф, а публичный калькулятор и админская панель разделены по разным маршрутам.

## Что умеет сервис

- рассчитывать итоговый коэффициент и диапазон цены ОСАГО;
- хранить и редактировать справочники коэффициентов;
- отдавать все справочники одним запросом;
- загружать типовые данные через сидеры;
- показывать отдельный публичный интерфейс и отдельную админ-панель.

## Быстрый обзор маршрутов

- `GET /` — публичный калькулятор
- `GET /admin` — админ-панель
- `GET /api/all-models` — все справочники одним ответом
- `POST /api/calculate-coefficient` — расчёт коэффициента и цен

## Хранилище

Сервис использует базу `openapi` в MongoDB. Коллекции:

- `places`
- `powers`
- `kbms`
- `age_experiences`
- `seasons`
- `limitations`
- `base_prices`

## Важные нюансы

- Для `Place` и `Power` поле коэффициента называется `coefficient`.
- Если полис без ограничения по водителям, `КБМ` и `КВС` принудительно равны `1.0`.
- Для сезонности при сроке использования от 9 месяцев коэффициент становится `1.0`.
- В расчёте используется самая свежая запись `BasePrice` по `created_at`, хотя `GET /api/all-models` возвращает весь список `base_price`.
