# AGENTS

Краткая памятка по проекту для дальнейшей доработки.

## Что делает проект

- Axum API для расчёта стоимости ОСАГО.
- Публичный интерфейс на `/`.
- Отдельный админский интерфейс на `/admin`.
- MongoDB хранит все справочники коэффициентов и базовый тариф.

## Основные команды

```bash
cargo run --bin openapi
```

```bash
cargo test
```

```bash
cargo fmt
```

## Наполнение справочников

Сначала загружаются типовые коэффициенты:

```bash
cargo run --bin seed_reference_data
```

Территориальные коэффициенты загружаются отдельно из `data/place.html`:

```bash
cargo run --bin seed_places
```

## Важные детали

- Для `place` и `power` в Mongo используется поле `coefficent` по историческим причинам.
- Для неограниченного полиса логика расчёта выставляет `КБМ = 1.0` и `КВС = 1.0`; `КО` берётся из справочника `limitation`.
- Для `base_price` в расчёте используется самая свежая запись по `created_at`.
- Админские API-маршруты живут под `/admin/*` и защищены Bearer-токеном из `ADMIN_TOKEN`.
