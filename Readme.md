# ОСАГО API

## Описание

Этот сервис предоставляет API для расчёта стоимости ОСАГО на основе базовой ставки и коэффициентов. Он позволяет управлять такими сущностями как **Place**, **Power**, **KBM** и использовать коэффициенты для расчёта стоимости полиса.

## Преимущества

- Поддержка динамических коэффициентов для расчёта ОСАГО.
- Лёгкость в использовании и настройке.
- Современная архитектура на базе **Rust** и асинхронного фреймворка **AXUM**.

## Структура проекта

Проект состоит из нескольких компонентов:
1. **Контроллеры** (`controller`) — обработчики маршрутов API.
2. **Модели** (`models`) — структуры данных, используемые для взаимодействия с API.
3. **Конфигурации** (`config`) — настройки подключения к базе данных и другие параметры.

## Архитектура

Сервис использует следующие сущности:
- **Place** — представляет место для расчёта стоимости ОСАГО.
- **Power** — содержит информацию о мощности транспортного средства.
- **KBM** — коэффициент бонус-малус, который влияет на стоимость полиса.
