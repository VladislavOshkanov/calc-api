# ОСАГО API

REST API для расчёта стоимости ОСАГО на основе базовой ставки и коэффициентов (место, мощность, КБМ).

## Общее описание
Этот проект является RESTful веб-сервисом, предназначенным для расчёта стоимости ОСАГО на основе различных коэффициентов. Основные возможности включают создание, чтение, обновление и удаление (CRUD) данных о местах, мощностях, КБМ, а также управление административными маршрутами с использованием Bearer токена для авторизации.

## Функциональные возможности
### Места (Places)
- **Создание**: Добавление нового места с указанием названия и коэффициента.
- **Чтение**: Получение информации о конкретном месте по его идентификатору.
- **Обновление**: Изменение данных существующего места.
- **Удаление**: Удаление места из базы данных.

### Мощность (Powers)
- Аналогичные CRUD операции, но уже для объектов, представляющих мощность.

### КБМ (KBM)
- То же самое касается коэффициента бонус-малус (КБМ), включая все вышеперечисленные операции.

## Авторизация для Администраторов
Для доступа к административным маршрутам, таким как создание новых мест или изменение существующих, требуется авторизация с использованием Bearer токена. Пример запроса на добавление нового места:
```
POST /admin/place
Authorization: Bearer <token>
{
  "name": "Москва",
  "coefficent": 1.5
}
```

## Разработка и Запуск Проекта
### Требования
- Установите [Rust](https://www.rust-lang.org/) для компиляции кода на Rust.
- Установите MongoDB как систему управления базами данных (DBMS).

### Установка и Сборка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/VladislavOshkanov/calc-api.git
   cd calc-api
   ```
2. Соберите проект с помощью Cargo (менеджер зависимостей Rust):
   ```bash
   cargo build
   ```
3. Запустите сервер:
   ```bash
   cargo run
   ```
   По умолчанию сервер будет слушать порт 3000.
